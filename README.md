# Publicar tu currículum en GitHub Pages

Esta es una plantilla estática, adaptable a celular y computadora. No necesita servidor ni base de datos.

## 1. Personalizá los datos
Editá `index.html` y reemplazá los textos entre corchetes (`[Tu nombre]`, `[Puesto]`, etc.). Cambiá también:
- `tuemail@ejemplo.com`
- `https://www.linkedin.com/in/tu-usuario`
- `https://github.com/tu-usuario`

Si todavía no tenés proyectos publicados, podés quitar esa sección o enlazar repositorios reales.

## 2. (Opcional) Agregá el CV en PDF
Poné tu archivo en esta carpeta y nombralo exactamente `cv.pdf`. Si no querés publicar un PDF, eliminá el enlace "Ver CV PDF" del archivo `index.html`.

## 3. Creá el repositorio
1. Entrá a https://github.com/ e iniciá sesión o creá una cuenta.
2. Creá un repositorio nuevo llamado **exactamente** `TUUSUARIO.github.io`, sustituyendo `TUUSUARIO` por tu nombre de usuario de GitHub.
3. Elegí **Public** y creá el repositorio.

## 4. Subí los archivos
Dentro del repositorio, usá **Add file → Upload files** y subí `index.html` y `style.css` (y `cv.pdf`, si corresponde). Confirmá con **Commit changes**.

## 5. Activá GitHub Pages
En el repositorio, entrá a **Settings → Pages**. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná la rama `main` y la carpeta `/(root)`, y guardá si hace falta.

La web debería publicarse en:
`https://TUUSUARIO.github.io/`

La primera publicación puede tardar unos minutos.

## Privacidad
Todo lo que publiques en el sitio y en el repositorio público podrá verlo cualquiera. No incluyas DNI, domicilio exacto, contraseñas, datos de clientes ni información privada. Usá un email profesional si preferís no exponer tu correo personal.

## Actualizaciones
Para cambiar el CV, editá `index.html` en GitHub o subí los archivos actualizados. GitHub Pages vuelve a publicar los cambios automáticamente.
